===== 체크포인트 재개 기능 완료 =====

✅ 구현 완료:

1. train_real.py 수정
   - start_epoch 파라미터 추가
   - optimizer_state 로드 기능
   - 체크포인트 경로를 두 번째 인자로 받음

2. train.py 수정
   - 동일한 재개 기능 추가
   - 간단한 데이터셋에도 적용 가능

3. resume_train.py (새 파일)
   - 가장 최근 체크포인트 자동 찾기
   - 체크포인트 목록 표시
   - 편리한 재개 스크립트

4. 문서 작성
   - RESUME_GUIDE.md: 상세한 재개 가이드
   - EXAMPLES.md: 다양한 사용 예제
   - README.md 업데이트
   - USAGE.md 업데이트

===== 사용법 =====

# 방법 1: 자동 재개 (가장 간단)
python resume_train.py lego

# 방법 2: 특정 체크포인트 선택
python resume_train.py lego nerf_epoch_20.pth

# 방법 3: 직접 지정
python train_real.py lego nerf_final.pth

# 체크포인트 목록 확인
python resume_train.py lego list

===== 주요 기능 =====

✅ 모델 가중치 복원
✅ Optimizer 상태 복원 (learning rate, momentum 등)
✅ 에폭 번호 자동 설정 (저장된 다음부터 시작)
✅ 이전 loss 정보 표시
✅ 체크포인트 자동 검색
✅ 에러 처리 (체크포인트 없을 시 경고)

===== 예제 =====

1. 추가 학습 예제:
   - 30 에폭 학습 완료
   - config.py에서 n_epochs를 50으로 변경
   - python resume_train.py lego
   - → 30부터 50까지 20 에폭 추가 학습

2. Fine-tuning 예제:
   - 학습 완료 후
   - config.py에서 lr을 5e-4 → 1e-4로 변경
   - python resume_train.py lego
   - → 낮은 learning rate로 fine-tuning

3. 중단 후 재개:
   - 학습 중 Ctrl+C로 중단
   - python resume_train.py lego
   - → 가장 최근 체크포인트부터 자동 재개
